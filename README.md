# Engineering Portfolio — starter site

A responsive, static HTML/CSS portfolio starter for GitHub Pages. No framework, build step, or JavaScript dependency is required.

## Files

- `index.html` — home page and project cards
- `about.html` — short bio and interests
- `projects/shelf-stabilizer.html` — Sandy Vans case-study starter
- `projects/smartlet.html` — Smartlet case-study starter
- `projects/frc.html` — FRC mechanical-design case-study starter
- `assets/css/style.css` — shared visual styles
- `assets/images/` — add your approved project photos and diagrams here

## Preview locally

Open `index.html` in a browser. For the best testing, use VS Code with a local static server extension, or run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` for a personal site.
2. Upload the contents of this folder to the repository root. `index.html` must be in the root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, select deploying from the `main` branch and the `/ (root)` folder if prompted.
5. Save and wait for the published URL to appear. GitHub Pages can take several minutes to deploy.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Before publishing

- Replace the diagram-style placeholders with your own approved photos, CAD screenshots, and annotated diagrams.
- Review every project description for accuracy and distinguish proposed concepts from tested results.
- Get permission before publishing employer or team material that may be confidential.
- Do not upload private information, credentials, or internal files.
- Add an appropriate professional contact method only if you want it public.
- If you use a repository other than `YOUR-USERNAME.github.io`, links may need to be adjusted for the repository subpath.

## Design notes

The site uses a warm off-white background, charcoal text, muted green accents, thin rules, and monospaced labels. The schematic illustrations on the home page are CSS-made decorative placeholders, not photos or representations of exact manufactured geometry.
